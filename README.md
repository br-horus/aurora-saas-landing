# ✦ AURORA — SaaS Landing Page

> A cinematic SaaS landing page with animated aurora gradient background, glassmorphism dashboard mockup, live chart bars, pricing tiers, and testimonials. Pure HTML/CSS/JS — zero dependencies.

## ✨ Features

- Animated aurora gradient background (18s shift)
- Noise texture overlay for depth
- Glassmorphism dashboard mockup with live chart bars
- Gradient text animation
- 3-tier pricing with featured plan
- KPI cards with animated values
- Full responsive
- Scroll-reveal + parallax mockup

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JS
- Glassmorphism
- CSS Animations

## 🚀 Quick Start

```bash
# Just open it — no build step, no dependencies
open index.html
# or serve it:
python3 -m http.server 8080
# then visit http://localhost:8080
```

## 📁 Structure

```
index.html   ← complete app (HTML + CSS + JS inline)
```

## 🎨 Design System

- **Fonts:** Space Grotesk / Outfit / Plus Jakarta Sans (Google Fonts)
- **Colors:** Custom CSS variables — easy to re-theme
- **Animations:** Pure CSS keyframes + IntersectionObserver
- **Icons:** Emoji + Unicode (no icon library needed)
